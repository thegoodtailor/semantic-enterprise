== Foundations and Sources

The ideas in this book have long lineages. This essay names them: what is inherited, from whom, and where this book departs.

The formal spine is decades-old mathematics that has just found its moment. Composing many domain theories into one — gluing them along what they share, the pushouts and colimits of category theory — was worked out for program synthesis in the 1990s, long before anyone needed it for data. It is what the agentic estate requires: a principled way to fuse a hundred local vocabularies into one coherent whole an agent can reason across, with every loss and gap made explicit rather than papered over.

This is the construction I developed with Crossley and Wirsing in the late 1990s: a logical calculus whose structural rules were exactly the operations for modifying specifications — renaming, hiding, and taking unions, that last being the pushout (WADT'99; the framework later generalized across deductive systems and gathered in our 2005 monograph). Here it is transported from specifications of programs to the integration of data models — where the gluing is cheaper to state, and the hard part is no longer the static composition but its evolution.

David Spivak's functorial data migration and ologs (2012, 2014) are the recent database-specific instance of the same categorical intuition, modeling schemas as categories and migrations as functors between fixed schema maps; that work moves instances along a given map, where the concern here is composing and evolving the schemas themselves. The parent is the specification-composition tradition; Spivak is the cousin. Where this book departs from both: the colimit here is a dynamic trajectory across organizational evolution — an eval target with gaps, maintained by agents, not a completed mathematical object. The mathematics of the gluing was settled decades ago. What is new is operationalizing it for data platforms that change faster than any formal specification can track.

Bitemporality — valid time versus system time, the two-axis row, the three query modes — inherits from Richard Snodgrass's foundational work on temporal databases (2000) and the SQL:2011 standard for temporal tables. The three query modes in this book (as-of-now, as-of-valid-time, as-of-report-time) correspond to Snodgrass's current, sequenced, and nonsequenced temporal query taxonomy. The relabeling into practitioner language is deliberate. Where this book adds: bitemporality as the default for the entire Silver substrate (not an opt-in feature for regulated workloads), and the extension to bitemporal ontology — ontologies themselves as versioned, temporal objects.

Domain-specific vocabularies connected by structure-preserving translations echo Joseph Goguen's theory of institutions (1992) — formal systems glued together by truth-preserving maps, and the logical home of the specification-composition tradition above: the maps along which specifications are glued are institution morphisms. Morphism honesty discipline in this book is institutions made operational: the maps' losses, partialities, and verification state become first-class documented objects. The bridges this book glues by pushout are exactly such maps, made to carry their own honesty data.

Dimensional modeling's durable principles — grain discipline, conformed dimensions, slowly changing dimensions — were articulated by Ralph Kimball across multiple editions of _The Data Warehouse Toolkit_ (1996–2013). Bill Inmon's corporate information factory established subject-oriented integration as an architectural principle. This book inherits specific principles from both traditions while claiming allegiance to neither. The synthesis — domain-canonical Silver built for columnar engines, flat Gold as strong default alongside Silver-as-Gold views for dimensional depth, semantic layer as the logical ontology governing both — is its own position, shaped by constraints that did not exist when either tradition was formalized.

Zhamak Dehghani's data mesh (2022) is the source of the domain-ownership principle the Architecture chapter defends and qualifies. This book's critique — that mesh underspecifies the semantic layer, producing federation without composition — is a critique of implementation gaps, not of the ownership principle. Federated governance as practiced here owes mesh more than the critique suggests.

This book prescribes prose documentation (domain essays of 600–1500 words) over structured knowledge representation (OWL ontologies, SPARQL endpoints, formal description logics) — a deliberate break with the Semantic Web program, whose OWL, RDF, and linked data were built precisely for machine reasoning. The dominant machine consumer of documentation has shifted from symbolic reasoners, which process OWL, to LLMs, which process natural language. OWL was correct for its consumer; prose is correct for this one.

Structured metadata anchors (datatypes, keys, refresh cadence, lineage) that survive from the ISO 11179 tradition serve the cross-reference and integration functions that structured formats handle well. Semantic weight — the operational knowledge that determines whether an agent reasons correctly or plausibly — lives in the essay. Both formats, serving different functions, governed together.
